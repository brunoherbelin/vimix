vimix for Windows (portable)
============================

Run bin\vimix.exe. Nothing needs to be installed: vimix, its libraries and
the GStreamer plugins are all in this folder, which can be moved anywhere.
Requires 64-bit Windows 10 version 1903 or later, or Windows 11.

Settings are stored in %APPDATA%\vimix.

The first start can take a while, as GStreamer builds the list of its plugins.

Not available yet on Windows: pen pressure of tablets, discovery of other
vimix on the network (mDNS), Shmdata output, Frei0r plugins, and the RIFE
frame interpolation and Real-ESRGAN upscaling (NCNN / ONNX).
